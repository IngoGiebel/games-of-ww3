# GWW3 — Branding Guidelines

## Logo
- **Primary:** `gww3-logo.jpg` (1024×1024, Gemini-generated)
- **Concept:** "Shattered Globe" — fractured world with golden fault lines
- **Icon variant:** TODO (simplified for favicon/avatar use)

## Color Palette
| Name | Hex | Usage |
|------|-----|-------|
| Midnight Navy | `#0A1628` | Primary background |
| Steel Blue | `#1B2A4A` | Panels, map surfaces |
| Command Gold | `#D4A017` | Highlights, borders, accents |
| Conflict Red | `#C41E3A` | Conflicts, alerts, losses |
| Alliance Green | `#2E8B57` | Allies, positive trends |
| Fog of War | `#8B9DAF` | Secondary text, disabled |
| Deep Ops | `#0F1F38` | Overlays, sidebar |
| Signal White | `#E8ECF1` | Primary text |

## Typography
| Use | Font | Style |
|-----|------|-------|
| Headlines | Oswald | Bold, Condensed |
| UI / Body | Inter | Regular / Medium |
| Data / Numbers | JetBrains Mono | Monospace |

## Tagline
**"Every nation. Every decision. Every consequence."**

## Tone
- In-game: military-concise ("Sanctions imposed. GDP impact: -4.7%")
- Marketing: epic but data-driven ("Real data. Real consequences.")
- Community: enthusiastic ("We just loaded 231,000 ACLED events!")
