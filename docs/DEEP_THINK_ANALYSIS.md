## Key Insights (Consolidated)

### Q1: Balancing — Emergent Friction Framework
- **Power Projection Friction:** Cost scales non-linearly with distance
- **Asymmetric Cost-Exchange:** Insurgencies drain superpowers economically ($500 drone vs $2M cruise missile)
- **Domestic Political Capital:** War weariness × media freedom = constraint on democracies
- **Emergent De-Dollarization:** Overuse of sanctions triggers alternative blocs organically

### Q2: War Financing — Sovereign Sustainability Framework
- **Trilemma:** Taxes vs. Debt vs. Money-printing (each with toxic side-effects)
- **Daily Burn Rate** formula for war costs
- **Graph-Based Sanctions:** Shortest-path evasion with middleman premiums
- **Capitulation Threshold:** Economic Strain Index forces peace even with intact military

### Q3: Real-Time Model — Multi-Resolution Time Architecture
- **Ingo Override:** 1 tick = 1 MINUTE minimum (not 1 second) for agent reaction time
- **Multi-resolution loops:** Tactical (daily), Diplomatic (weekly), Economic (monthly), Epoch (annual)
- **Decision Latency:** Bureaucracy engine with regime-dependent delays
- **Event-Driven Interrupts:** Emergency Cabinet for critical state changes

### Q4: Agent Consensus — AIGA Protocol
- **Information Siloing:** Agents only see their department's data
- **Conflicting Utility Functions:** Structural friction via orthogonal KPIs
- **Cabinet Debate:** 3-phase protocol (Briefing → Cross-Exam → Resolution)
- **Hubris/Paranoia:** Authoritarian regimes get filtered intelligence, crisis = higher LLM temperature

### Q5: Gap Synthesis — 6 Prioritized Design Gaps
1. Supply Chain Granularity (Critical)
2. Spatial Infrastructure Routing (Critical)
3. Space & Cyber domains (High)
4. Financial Leverage Networks (High)
5. Sub-National Factions (Medium)
6. Climate Shocks & Migration (Medium)

---

## Ingo's Design Decisions (23.03.2026)

1. **Tick = 1 Minute minimum** (game may run longer, that's fine)
2. **Top 20 nations by concrete players**, others auto-simulated; ideally ALL played
3. **ALL temporal data in Neo4j** — no separate time-series DB; temporal nodes linked to data nodes
4. **State changes = programmatic/rule-based** from agent decisions (not LLM-evaluated)
5. **Player = Head of State only**, internal parties/factions simulated (partly random)
6. **Internal tensions modeled** via faction nodes with competing interests
